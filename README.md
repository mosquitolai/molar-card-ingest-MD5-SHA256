## English
**MolarCard** is a high-performance macOS backup utility designed for memory cards and external hard drives. Built with an intuitive graphical interface, it delivers a secure and highly stable data transfer solution tailored for photographers, videographers, and creative professionals. Powered by industry-standard cryptographic verification, MolarCard effectively prevents file corruption and data loss during transfers, ensuring every byte of your critical data is flawlessly backed up.

### ✨ Key Features
*   🛡️ **Data Integrity Check**: Built-in MD5 and SHA-256 hash algorithms for bit-for-bit verification, eliminating corruption risks.
*   🌍 **Multi-Language Support**: Seamlessly switch between 8 languages.
*   🎨 **Custom Themes**: Choose from Dark, Light, or a unique Milk Tea theme to match your workflow.
*   💽 **Device Management**: Auto-detects and monitors the capacity and health of connected SD/CFexpress cards and drives.
*   📜 **History & Logs**: Keeps detailed records of all backup tasks, timestamps, and hash verification results.
